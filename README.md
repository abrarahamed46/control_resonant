Resonant Platform Shift Mechanism
A dynamic, physics-based puzzle and traversal system built in Unreal Engine using Blueprints and Line Traces. This project demonstrates responsive platform manipulation where shifting mechanisms resonate and trigger movement based on player position and interaction.

Overview
This project implements a platform shifting system designed for environmental puzzles and dynamic platforming mechanics. By leveraging single and multi-line traces, the system continuously samples surface data, alignment, and trigger boundaries to transition platforms seamlessly between states.

Key Features
Line Trace Target Detection: Uses optimized line tracing (raycasting) to accurately detect player presence, proximity, and surface intersections.

Resonant State Switching: Custom blueprint logic drives fluid platform state transitions (e.g., elevation change, rotation, shift alignment) upon activation.

100% Visual Scripting: Completely authored in Unreal Engine Blueprints for modularity, clarity, and ease of expansion.

Modular Setup: Easily attachable to any static mesh or environmental actor to create custom platforming sequences.
Version Of Unreal Engine 5.6
